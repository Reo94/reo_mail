# GitHub Checkpoint

## Suggested Commit

`Add player-to-player persistent mail delivery`

## Suggested Commit Description

Adds the first tested end-to-end player-to-player postal flow to REO Mail. Players can identify their persistent PO Box, compose a letter to another PO Box, deliver it into the recipient's persistent mailbox, claim the physical envelope, open it, and read the letter.

Also includes server-side physical-envelope opening and validation improvements.

## Release Decision

Push this checkpoint to the repository's main development branch, but do **not** create a new GitHub Release/tag yet. Keep the existing v0.1.0 proof-of-concept release as the latest formal release while development continues toward the next milestone.
