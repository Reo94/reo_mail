# Changelog

## v0.1.0 — Core Mail Proof of Concept

### Added
- Persistent character postal profiles and permanent PO Boxes.
- Qbox/QBX character integration.
- Persistent database-backed mail records.
- Unique REO tracking numbers.
- Mailbox retrieval and mail-reading flow.
- Physical `reo_envelope` inventory item with postal metadata.
- Claim-envelope workflow with duplicate-claim protection.
- Physical envelope inspection.
- Sealed/opened envelope state.
- Open-envelope and read-letter interactions.
- Server-side ownership and postal-record validation.
- Inventory-space failure handling.

### Development Status
This release validates the core physical-mail lifecycle and serves as the foundation for the larger REO Mail postal framework.
