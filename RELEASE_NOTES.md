# REO Mail v0.1.0 — Core Mail Proof of Concept

REO Mail v0.1.0 is the first functional proof-of-concept release of REO Development's server-wide physical postal framework for FiveM.

This milestone validates the core mail lifecycle:

**Create → Store → Mailbox → Claim → Inspect → Open → Read**

## Included
- Persistent postal profiles and permanent PO Boxes
- Qbox/QBX character integration
- Persistent mail storage
- Unique tracking numbers
- Mailbox access
- Physical ox_inventory envelopes
- Postal metadata
- Envelope claiming
- Sealed/opened envelope interaction
- Physical letter reading
- Server-side ownership validation
- Duplicate claim protection

## Not Yet Implemented
- Housing/property address integration
- Business addresses
- Physical world mailboxes
- Player-to-player mail composition
- Packages and certified mail
- Automated mail from external resources
- Government/document integrations
- Postal sorting and delivery routes
- Playable postal worker job

> This is an early development build and is not considered feature complete or production ready.
